## How to use a template
1. Open the diagram's folder and read the notes: when to use it and the decisions it makes.
2. Click **Open in Planloom** to edit it as real shapes, or copy `diagram.mmd` into your own docs.
3. Replace the placeholder names with your own services, then share the board with your team.

Mermaid also renders natively in GitHub Markdown, so you can commit the same source to your repo's docs and keep the picture next to the code. See [GitHub's documentation on Mermaid diagrams](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams).
